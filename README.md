# גודל אמיתי · Real Size

מסע אינטראקטיבי בין גדלים — מחיידק E. coli (2 מיקרומטר) ועד בורג׳ ח׳ליפה (828 מ׳).
An interactive journey through sizes, from an E. coli bacterium (2 µm) to the Burj Khalifa (828 m).

**אתר חי / Live site:** https://yaakov3h.github.io/real-size/

## מה יש כאן / Features

- 36 דמויות: 30 יצורים חיים ו-6 מבנים מפורסמים, מסודרים בסולם לוגריתמי.
- 36 figures: 30 living things and 6 famous structures on a log scale.
- החלקה (מגע), מקשי חצים, קפיצה להתחלה/לסוף, רשימה מלאה, סיור אוטומטי ויצור אקראי.
- **תצוגת השוואה בקנה מידה אמיתי** — שתי דמויות זו ליד זו על קו קרקע משותף, עם קו יחס, סרגל קנה מידה, וזכוכית מגדלת לדמות הקטנה.
- **True-scale comparison view** — two figures side by side on a shared ground line, with a ratio line, scale bar, and a magnifier for the tiny one.
- עברית/English בלחיצה אחת (נשמר בדפדפן, כולל כיוון RTL/LTR).
- נגישות: aria-labels, מקלדת, ניגודיות, העדפת reduced-motion.
- כל גודל מלווה במקור (ויקיפדיה ומקורות נוספים). מבנים מסומנים בתג ״מבנה״ ובריבועים סגולים בסרגל.
